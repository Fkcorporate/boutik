Supprimer mon compte Boutik

Application Boutik (web, Android et iPhone) · éditeur : l'éditeur de Boutik

Le compte Boutik, c'est votre boutique en ligne : ses produits, ventes, vendeurs, dépenses, crédits et réglages enregistrés sur notre serveur. La suppression est définitive : toutes ces données sont effacées de notre serveur, et la synchronisation s'arrête sur tous les téléphones de la boutique.

Conservées : les paiements de l'abonnement (date et montant) dans notre comptabilité, comme la loi l'exige. Rien d'autre.

1. Depuis l'application (le plus simple)

Ouvrez Boutik avec le compte propriétaire, puis Plus → Paramètres → Compte → Supprimer mon compte. Confirmez avec votre code secret ou votre empreinte.

2. Ici, avec le code de votre boutique

Dans l'appli : Paramètres → Suivi à distance → Connecter un autre téléphone. Un code qui commence par BOUTIK1| s'affiche : copiez-le ici.

3. Sans l'application

Vous n'avez plus l'appli ou plus votre téléphone ? Envoyez-nous une demande : nous vérifions que vous êtes bien le propriétaire, puis nous supprimons le compte sous 30 jours au plus tard, et vous prévenons.

Et les données sur le téléphone ?

Ce qui est enregistré sur un téléphone s'efface en désinstallant l'application, ou dans l'appli : Paramètres → Effacer toutes les données.
