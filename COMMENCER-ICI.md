# Boutik — par où commencer

1. **`boutik-server/`** : à mettre en ligne sur Render (voir `boutik-server/LISEZMOI.md`). Vous obtenez :
   - le site vitrine (`/`) ;
   - l'appli web (`/app/`) ;
   - votre console (`/admin`) ;
   - la page de confidentialité (`/confidentialite`).
2. **`boutik-mobile/`** : l'application Android et iPhone pour les stores (voir `boutik-mobile/GUIDE-STORES.md`). À faire **après** la mise en ligne du serveur, car l'application a besoin de son adresse.
